## 固定的数据规则

沿用已有索引的全部 288,422 个默认配置事件，共 23,148,582 个有效帧，涉及 47,453 条去重文本。训练集为 247,211 个片段、19,701,431 帧。事件仍是 30–300 帧，官方测试归属、派生验证集和镜像冲突隔离规则均不改变。

每个片段独立执行：

1. 从节点 NPZ 按固定帧范围读取局部旋转和根位置。
2. 减去实际首帧 root 的 X/Z 平移，保留 Y 高度和原始 heading；保存平移偏移供回放恢复。
3. 使用官方 `KimodoMotionRep` 重算 FK、片段尺度平滑 root、世界系线速度、heading 和脚接触。
4. 按原有布局拼接 `[smooth_root(3), heading(2), node_pos(102), global_rot6d(204), velocity(102), contact(4)]`。
5. 以 float64 做几何计算，将结果保存为 float32；在保存值上计算统计量。

不直接切下完整动作的 smooth-root/速度/接触缓存，也不在缓存中随机旋转 heading。后续如果加入 heading 增广，必须同步变换相关特征并在归一化前执行，不能只改变条件角。

缓存中的坐标为 Kimodo Y-up、+Z forward。节点位置特征减去平滑 root 的水平坐标并保留世界高度；旋转特征是全局旋转矩阵的前两列。归一化后的旋转六维数不能直接当作合法旋转解码，必须先反归一化。

## 归一化

只累计 train 的真实有效帧，不包含 padding、val 或任一测试集。统计按帧等权，使用 float64 的合并均值/中心矩，方差定义为总体方差（ddof=0）。每个分片均不跨样本计算速度；额外的四维 local-root 统计也在每个片段内生成。

与当前官方 `Stats` 完全同口径：

```text
normalized = (raw - mean) / sqrt(std**2 + 1e-5)
raw        = normalized * sqrt(std**2 + 1e-5) + mean
```

磁盘只保存一份未归一化动作缓存。Dataset 按这些固定统计量读取并返回归一化 `x0`，无需复制一份同体积的归一化数据。

## 文本缓存

使用现有本地 Llama 3 8B、MNTP 和 supervised adapter，保持 Kimodo 已验证的本地 wrapper 行为、mean pooling、空 instruction、BF16 基础模型和内部 `batch_size=1`。所有编码器参数冻结，输出缓存为 float32，不额外对句向量做单位长度归一化。

文件 SHA、tokenizer、依赖版本、提示模板行为均写入配置。缓存前与此前保存的四条基准文本向量精确比较，检查文本没有触发长度截断；完成后重复计算首、中、末三条并与缓存精确比对。使用固定编码器计算验证和测试文本向量，不会用这些数据更新模型或拟合动作统计量。

当前本地 `_name_or_path` 对提示模板分支的影响沿用已验证基线，不声称等同于所有上游部署方式。由于变长 padding 的已知边界，不能为提速直接改变内部 batch size。

## 模型读取接口

在项目根目录、激活 `.venv` 后：

```python
from torch.utils.data import DataLoader
from data_pipeline.model_input_dataset import G1ModelInputDataset, collate_model_inputs

dataset = G1ModelInputDataset("train")
loader = DataLoader(dataset, batch_size=4, num_workers=0,
                    shuffle=True, collate_fn=collate_model_inputs)
batch = next(iter(loader))

print(batch["x0"].shape)                 # [B,Tmax,417]，归一化干净动作
print(batch["text_feat"].shape)          # [B,1,4096]
print(batch["x_pad_mask"].shape)         # [B,Tmax]，True=真实帧
print(batch["text_feat_pad_mask"].shape) # [B,1]
print(batch["first_heading_angle"].shape)# [B]，原始首帧 heading，弧度
```

零 padding 在归一化之后添加；损失和统计必须遵守 `x_pad_mask`。额外文本 token 如由网络需要，应在网络内构建，不把缓存扩为 50 个重复向量。

Tiny 可以通过 `G1ModelInputDataset("train", min_frames=60, max_frames=90)` 选择已有 2–3 秒事件，不重新随机裁剪这些事件。Dataset 使用只读 mmap 缓存分片和文本，支持多 worker；多进程脚本须使用主入口保护。

实例化 Kimodo 去噪器时，`motion_rep` 的 `stats_path` 应指向本目录的 `stats/motion/`。从零训练应使用随机去噪器权重，不加载官方动作 checkpoint。训练程序还需自己采样扩散时间步和噪声，Dataset 不保存它们。
