## 2. 新采样器：只调整91–120帧跳跃内部的抽取

训练GT覆盖诊断已发现，该格有效幅度中位数训练8.83cm、开发23.12cm。新的训练池按原物理GT骨盆Y的P90−P10计算幅度：原混合集共有158条该长度跳跃，至少20cm的15条，其余143条全部保留。15/158=9.49%包含所有该格事件；此前15/118=12.71%的分母仅包括达到原评估GT有效阈值的事件，二者不混用。

新增 `training/m5_amplitude_sampling.py` 与 `scripts/train_m5_amplitude_sampling.py`：

- 先用原长度/类别分层采样器抽取原批次。仅将91–120帧jump位置在高/低幅度池重新抽取，目标高幅度比例为50%；其他位置的事件索引保持原样。
- 原batch RNG仍按原算法消耗，幅度混合使用独立CPU RNG（seed+7919）。新增随机状态、operator、pool身份和概率进入checkpoint，恢复时核对。
- 这不是“只重采样一半位置”：被选中的该格jump位置从两个池重新抽，50%描述高幅度混合概率。原低幅度事件没有被删掉。
- 每文本cap20仍指视图中独立训练事件数。采样曝光会改变，各文本/类别/长度曝光继续保存在`exposure_counts.json`，不能把独立事件上限当作曝光次数上限。
- 新CLI直接记录本次真实更新的`last_indices`。原CLI仅回退batch RNG的peek不能回退新增混合RNG，因此没有复用那种记录方式，也未修改原工作入口。
