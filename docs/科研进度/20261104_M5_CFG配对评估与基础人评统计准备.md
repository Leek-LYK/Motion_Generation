# 2026-11-04｜CFG配对评估收束与V3基础人评统计准备

本轮不新增optimizer更新。冻结T2_60 EMA，对同一180条基础开发事件比较CFG1/1.5/2，共3,240段生成；结果显示较低CFG降低几何误差，但基础幅度相对退化超限，**当前保持CFG2**。短序列控制训练及其固定评估口径保持原样。

同时新增V3基础人评统计引擎，按80条基础必评、40条复杂展示可选处理。验证均为明确标记的合成夹具，没有增加真实评阅者或修改用户评分。

## 1. CFG研究设计与出处核对

原完整计划第9.1节已允许CFG1/1.5/2作为开发候选。三组使用同一T2_60 checkpoint、EMA、训练统计、文本缓存、180事件顺序、batch16、DDIM100、seeds0/42/1234及native/heading0。每组1,080段，共享相同事件/seed/朝向键和初始噪声。

基础子集与原300事件重新分批后可能出现数值差异，因此CFG2也按相同180事件布局重新生成，作本研究控制；原CFG2文件保留。所有模型及checkpoint身份、GT参考幅度和1,080个配对键已核对。24个固定布局回归例的归一化特征与旧CFG2结果最大差为0，整体pooled投影与最大值也一致，均值差约1e-9。

读取发布代码确认：`Kimodo`在完整denoiser外包装CFG，Twostage内部仍为Root→Body；现有工厂`use_text_mask=False`会覆盖文本mask。没有发现需要把CFG改成“分别引导Root、再给Body”的工程缺陷，原训练/采样源码保持冻结。

需要注意的是，CFG是对网络输出的线性外推，而6D旋转归一化、FK和合法hinge集合是非线性的。一个解析单位连杆例子中，条件/空条件各为合法±30°、合法范围±45°；CFG2外推后旋转为60°，位置头与FK也不再一致。这个例子只说明机制可能性，不是实际模型质量的证据。

CFG1.5对应几何改善10.89%/11.31%，其他关键几何相对保护通过；其heading0普通转向非坍缩从控制66/72=91.67%降至60/72=83.33%，下降8.33pp，超过预注册5pp保护，也未选用。72个片段来自24条有效参考的三次采样，不能当作72条独立运动。

三组都通过基本幅度的绝对比例/中位数要求，但相对可靠性保护仍有区别。当前不以较低几何分数抵消基础动作退化，也没有据此降低转向门槛、改难度标签或为每个提示单选CFG。原默认CFG2继续用于短控制与后续主比较。

所有基础绝对几何仍未达标，几何改善不能代替文本语义、最终80k训练或真人评价。此处是开发点对比，没有给出训练seed间的统计结论。

## 3. V3基础人评统计引擎

新增 `training/m5_basic_review_statistics.py`，不改原V2分析模块或用户已提交的CSV。引擎接收已由私有包绑定的模型/提示/难度映射，处理：

- 两个Small模型各自的80条基础提示，四类各至少20条独立提示/源簇。
- 两位独立评阅者的主动作分与配对偏好，平局计0.5；NFKC/casefold后的身份不得重复。
- 每个Small分别计算四类等权准确率、类别退化与源簇联合bootstrap偏好区间。重复评阅、不同生成seed和同源动作不冒充更多独立源。
- 复杂40条允许不填写或不提交评分；完整跳跃分不进入基础人评硬门槛。复杂表现不能补偿基础错误。
- 只有`source_final`、两个Small比较、完整基础覆盖与两个实际独立评阅条件满足时，才可能满足人评组件。模型80k课程、数值质量和657最终审计仍是单独要求。

这是统计引擎准备，不是最终评阅包已放行。最终模型及审计完成后，打包器还须绑定权重/代码/输入、源提示和匿名模型映射，才能使用实际评分。当前真实反馈仍只有用户本人对旧40k小包的一份。

## 4. 合成验证与实际反馈分开

合成夹具包含两个虚拟模型、每模型80基础＋40扩展、两个明确标记的合成评阅者。验证了80源簇不会变成160独立样本，复杂空白/零分不阻断，基础失败不能由复杂表现补偿，平局偏好CI=0.5不能通过“下界大于0.5”。

缺必评试次、重复试次、重复评阅身份、单一源冒充20提示会拒绝；基础空白或缺声明返回待完成。只有一位评阅者、只有一份Small比较、开发编写提示及合成数据均不能通过最终人评。已知合成声明会覆盖调用方遗漏的`synthetic`参数，避免测试夹具误当真人证据。

所有测试结果中的`human_gate_passed`均为false，没有创建或补写实际评审。旧版合成验证及源码另行保留，新结果见[统计引擎验证revision2](../../runs/m5_basic_scope_20261104/verification/basic_review_statistics_revision2.json)。

当前正式optimizer预算保持515k；本研究仅新增推理输出与统计程序。M5保持active，后续按基础短控制固定终点决定完整课程。
