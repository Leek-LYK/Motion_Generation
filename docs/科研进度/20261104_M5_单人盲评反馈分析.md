## 4. 对后续研究的影响

1. **先完成正在运行的固定 60k 因子对照。** 本次评价绑定旧 40k 两模型，不能拿它改变当前分支清单、预算或中途选型，也不能声称后续自一致性项已经修复这些问题。
2. **增加对左右、方向与复合时序的针对性检查。** 检查文本中的 left/right、身体关节命名、镜像规则及相机视角，并在同初始噪声的左右文本对照中观察抬臂和转向。将训练标签、坐标约定和模型学习区分开，在查明前不把所有方向错误归为转换器缺陷。
3. **用保留的原始 qpos 检查时间连续性和脚步协调。** 关注每帧 heading 变化、关节速度/加速度、接地附近脚的位移，以及 Root 位移与步态的关系。此类附加诊断应保留原输出，不先平滑后计算误差，也不把运动学接地代理当作动力学稳定性。
4. **继续单独检查完整跳跃和蹲起事件。** 起跳、腾空、落地及停稳，蹲下、保持、站起，应在回放中逐项观察。现有 Root 高度幅度及主动作分不能替代完整事件判断，原预注册要求保持原样。
5. **后续模型复用这十二提示作固定开发回归。** 保持文本、长度、采样 seed 和 heading；保留全部失败及原 40k 包，新增版本另存。后续人工回归仍按实际人数记账，开发小包不计入正式 120 条独立源提示的最终审阅。

论文中的 X/Z 根轨迹平滑已在当前输入链中使用并通过数值重放。它对水平根路径作平滑，不能由此推断生成的 heading、身体关节、接触和语义都连续正确。正文这些人工观察支持继续检查身体/方向/时序；尚不能直接推出增加某个损失或 dropout 就会改善质量。

当前不因本次反馈启动新的正式训练。现有三组因子研究继续原 60k 终点，独立 Small3102 的 0→40k 前缀已完成、质量结果保持不用于选配方；M5 总体仍在研究阶段。
