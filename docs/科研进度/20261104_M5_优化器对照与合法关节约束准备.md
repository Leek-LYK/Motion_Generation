## 3. Adam-atan2 单因素优化器对照

核对 [Kimodo 技术报告 §4.3](https://research.nvidia.com/labs/sil/projects/kimodo/assets/kimodo_tech_report.pdf) 后确认，论文使用 Adam-atan2、学习率 2e-5；文本阶段还使用网络 dropout 0.1 与均匀扩散时间采样。当前工程基线使用 AdamW、网络 dropout 0 和继承自 M4 的高噪声课程。这些差异分别记录，当前只对照优化器，不同时修改其他因素。

当前两个“七项”也有明确的项目定义差异：normalized 分支是六项均值再加权重为 1 的 FK；raw 分支使用七项给定权重并除以 44。它们同时改变权重与坐标域，不能将 B/C 解释为只改变了归一化。仅看系数，前者 FK/直接旋转比为 6；若同一归一化域使用给定的七项权重则为 0.5。该数值差异值得后续隔离，尚不能据此推断官方未公开的完整损失内部口径，当前六个分支均不改动损失定义。

新增 `training/adam_atan2.py` 与 `training/m5_atan2.py`，更新式按 [Everett 等人的附录 C.5](https://arxiv.org/html/2407.05872v2#A3.SS5) 实现：对偏差修正后的第一、第二矩计算 `a * atan2(m_hat, b * sqrt(v_hat))`，取 a=b=1，无 epsilon。本轮 betas=(0.9,0.999)、weight decay=0 与 AdamW 控制一致；Kimodo 未公开全部优化器常数，因此不声称完整复刻官方训练配置。

数值验证包括：闭式 NumPy 参考、正比例梯度缩放、零梯度与角度更新界、BF16 变长累积、包含非零物理项的逐位恢复。训练后的 AdamW 状态被拒绝作为 Adam-atan2 续训来源；共享初始权重只允许源 step=0 且目标优化器全新。

真实 Small CLI 另完成 16 步工程更新、验证和 qpos 导出，初始模型摘要与 Small raw 一致。相应 checkpoint 已通过视频导出验证。证据在 [adam_atan2/report.json](../../runs/m5_physical_20261103/verification/adam_atan2/report.json) 与 `verification/adam_atan2_cli/`，工程模型不参加质量排名。

正式分支 **O1_small_raw7_atan2** 从 Small raw 相同随机初始化开始，固定 **40k**。数据、种子、batch、损失、精度、学习率日程和增强相同，仅更换优化器。初始模型和首 1k 抽样轨迹已匹配。没有导入 AdamW 训练动量；恢复使用专门 schema，完整 lineage 单列。

协议：[adam_atan2/protocol.json](../../runs/m5_physical_20261103/auxiliary_protocols/adam_atan2/protocol.json)。原四组 160k，加匹配 Tiny raw 40k 与本次可选优化器研究 40k，本轮已登记总预算 **240k**。如果最终选择 Adam-atan2，现有 AdamW Tiny 不能代替最终匹配 Tiny。

在两个已知低姿态失败事件上，两个 Small 的 10k EMA 分别固定初始噪声、3 seeds、2 headings，对照 CFG=1/1.5/2，共 72 段。两事件长度为 96、131 帧，属于当前短片段训练范围之外的开发回归例。

Small raw 三个 CFG 的最坏穿地分别约 31.24 / 30.67 / 29.01 cm，调低 CFG 没有解决问题。Small normalized 的对应值约 46.58 / 76.91 / 88.16 cm，较低 CFG 减少极端值，但仍严重失败。不能凭两个失败例选择统一部署 CFG。

最后一步同时记录 conditional/null/guided 的 Root 和 Body 高度。负高度并非普遍由最后一步将两个正高度外推得到；它也可能已存在于对应 rollout 状态的条件或空条件预测中。该记录不证明更早步骤的原因。CFG2 回放与原评估的高度最大差分别约 9.66e-6 / 1.67e-6 m，批布局差异已记录。

证据位于 [guidance_height_010000](../../runs/m5_physical_20261103/diagnostics/guidance_height_010000/B1_small_norm7/report.json)。原训练/评估默认 CFG2 保持冻结，低姿态难例继续保留。

## 5. 物理约束校准和合法区间损失原型

`calibrate_m5_physical_constraints.py` 已在 10k 工程 fixture 中检查 8 个训练 batch 的 Body 梯度：自一致性、原生轴与地面项均有可用尺度，Root 额外梯度仅为数值零，参数未更新。正式模式要求最初四组 40k 完成且存在终点评估；**fixture 系数不能用于正式配方，40k 后须重新标定**。地面项允许在噪声参考上有非零残差，这一点单独记录。

仅有原生轴能量不能发现“绕正确轴但超出角度范围”的旋转。新增 `g1_legality_loss.py` 原型，以到 MJCF 合法 hinge 旋转集合的矩阵距离为损失。角度最小值在 Torch 中求解并停止该 argmin 的梯度，矩阵残差仍对预测保留梯度；没有把 CPU 导出器或 MuJoCo 放进反向传播。

检查结果：合法姿态最大残差约 1.85e-30；纯单轴越限反例被识别；与独立 bounded-angle 实现的旋转差约 4.44e-16；重新求最小值的有限差分误差约 5.89e-10；实际六维预测的旋转梯度有限且非零，padding 梯度为零。见 [legality_loss/report.json](../../runs/m5_physical_20261103/verification/legality_loss/report.json)。

原型没有选定训练系数，也没有接入任何运行中的模型。下一轮约束组合仍需终点依据、训练集梯度标定和单因素对照。
