## 动作特征与统计规则

每个片段先将实际首帧 root 的水平 X/Z 位置归零，保留 Y 高度和原始 heading。随后使用官方 `KimodoMotionRep` 在片段尺度重新计算 FK、平滑 root、世界系线速度、heading 与接触，不直接切取完整动作的派生缓存。

特征顺序为 `3 + 2 + 102 + 204 + 102 + 4 = 417`，几何计算采用 float64，磁盘保存 float32。按 split 存成连续 NPY 分片，无 padding；索引保存每条片段的分片路径、帧偏移、文本行号、初始 heading 和被移除的水平原点。

仅对 train 的有效帧按帧等权计算总体方差（ddof=0），不使用验证、测试或 padding。提供与官方接口一致的三组统计：

- `stats/motion/global_root/`：5 维。
- `stats/motion/body/`：412 维。
- `stats/motion/local_root/`：4 维，用于两阶段网络内部的 root 转换，不额外拼接到 417 维输入。

归一化公式为 `(raw - mean) / sqrt(std**2 + 1e-5)`。磁盘保存未归一化特征，Dataset 在读取时归一化，避免额外保存一份同体积的数据。

从实际训练缓存独立重读了所有训练帧，重新计算 417 维均值与标准差，并验证全部 966 个训练分片的 SHA-256。重算与保存结果最大差：均值 `2.44e-15`、标准差 `4.66e-15`。四维 local-root 统计同样仅由训练片段生成，其维度、有限值、版本及文件哈希经过核验；本次独立逐帧重算的维度范围为 417 维。

证据：[统计报告](../../data/processed/g1_model_inputs_v1/stats/report.json)、[独立全量审计](../../data/processed/g1_model_inputs_v1/stats/independent_audit.json)。
