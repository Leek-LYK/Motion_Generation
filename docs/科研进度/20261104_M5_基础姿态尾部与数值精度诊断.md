# 2026-11-04｜M5 基础姿态尾部与投影数值精度诊断

继续按用户调整后的[基础动作优先标准](20261104_M5_基础动作优先验收标准调整.md)工作。本诊断没有optimizer更新或DDIM自由生成。后续三组60k已收束，并单独启动必要的匹配短控制，见[三项对照收束与基础短控制启动](20261104_M5_三项对照收束与基础短控制启动.md)。

完成两项证据：先前GT最大合法性损失断言触发于FP32候选得分舍入，训练GT实际合法；随后在十二条基础训练事件、两个冻结raw模型上完成三十个批次的参数梯度诊断。尾部聚合和时序项具有较大的尺度变化与部分方向冲突，当前不选择系数、不加入正式训练。

## 1. GT断言的原因已经查明

先前十八条训练事件的诊断在长片段GT检查处停止，具体是左踝roll靠近上限的合法姿态：

| 项目 | 结果 |
|---|---:|
| 原GT最近合法角，FP64/独立NumPy一致 | 0.261529475 rad |
| 原生合法上限 | 0.2618 rad |
| FP32选出的相邻限位角 | 0.261799991 rad |
| 对应FP32单关节矩阵距离能量 | 7.3182e-8 |
| 相同native旋转的FP64/NumPy最近投影能量 | 4.1340e-15 |

当前Torch投影在FP32中比较候选的`a*cos(theta)+b*sin(theta)`。靠近限位时，合法内点与限位端点的分数差可小于FP32分辨率，`argmax`会先选中端点。这里角差约0.000271rad，即0.0155°。

CPU/CUDA分别检查十八条原训练事件，FP32最大值约6.84e-8/7.32e-8，而相同native旋转的FP64最大值约1.36e-13/1.42e-13。原有FP32平均能量检查仍通过，长批次均值约2.85e-12/5.87e-12。独立NumPy解一致。

另用解析生成的合法hinge旋转复现边界现象：距限位0.0001或0.0002rad的合法角，FP32仍可能选择端点，FP64恢复原角且能量接近零。该验证不涉及网络预测或动作难度分类。

因此，后续诊断保留原来的FP32平均能量界限，并使用相同1e-8界限检查FP64最近投影的最大值，同时完整记录FP32最大值。没有把投影器、输入缓存或正在运行的训练损失改掉。这个微小数值量级也不能解释已有生成中厘米至分米级的节点投影误差。

数值审计首次调用了表示对象不支持的`.to()`，修正为由Stats按数据设备处理；另一次在结果保存时遇到NumPy布尔值序列化错误。两次源码/日志均保留，没有参数更新。最终完整结果见[数值审计](../../runs/m5_physical_20261103/diagnostics/native_projection_numeric_20261104/report.json)。该审计使用编译MJCF常量，没有实例化去噪网络。

## 2. 新诊断只选择基础训练动作

从原3,366条混合训练事件中，按已冻结V3文本/类型分类筛出基础样本；四类walk/jog/raise_arms/turn×短/中/长，各用固定哈希选择一条，共十二条。没有根据生成分数选样，没有使用val/test或seed3102质量。

冻结raw训练模型为C40和已通过V3基础研究保护的T2_60；不用EMA替代训练模型。两个模型都以相同raw7＋G1自一致性定义作梯度参照，使用相同GT、固定yaw、每事件/t的相同噪声。分别检查t=0/249/499/749/999，batch4，BF16前向、FP32损失与参数梯度，共三十个批次、一百二十次事件去噪前向。

被检查的候选均只是原型：

- 原Native合法性均值。
- 每帧Top3关节的合法性均值。
- 每clip最差10%帧的Top3关节；clip间保留原有效帧数加权。
- Root的cos/sin方向向量对GT的30Hz差分监督。
- Body全局6D旋转对GT的30Hz差分监督。

GT检查通过：FP32均值满足原1e-8要求，FP64最大投影误差能量满足1e-8要求；时序项对GT自身为零。原型通过掩码值/梯度不变性、批次复制不变性、单位测试和双精度gradcheck。该验证不等于正式训练器已经完成实现。

## 3. 实际参数梯度量级

以下是T2_60三个长度批次中，**逐批次比值的中位数**，均为未乘系数的结果：

| t | 尾部合法性Body梯度 / 原均值合法性Body梯度 | Root时序梯度 / 主损失Root梯度 | Body时序梯度 / 主损失Body梯度 |
|---|---:|---:|---:|

| 499 | 17.36 | 108.04 | 72.97 |
| 749 | 15.25 | 103.41 | 61.33 |

C40各批次的尾部/均值梯度范数比范围为11.44–23.90，T2_60为13.64–20.35。改变归约后，不能把原均值合法性项的λ直接搬过来。逐帧Top3本身的增幅约5–9倍，也需要独立标定。

三十个参数梯度点中：尾部合法性与主Body梯度方向余弦为负的有4个；Root时序与主Root梯度为负的有14个；Body时序与主Body梯度为负的有9个。负余弦不是训练必然退化的证明，但说明这些目标在部分输入上存在方向冲突，不能把它们简单叠加。

原生合法性三种归约都没有直接进入Root参数的梯度，Root时序项也没有直接进入Body参数的梯度，符合训练时Root→Body条件detach的实现。增强Body合法性并不能直接约束Root方向；后续若采用时序项，须分支标定并检查基础方向/幅度的退化。

“尾部项输出梯度集中在所选10%帧”是其定义带来的结果，不是模型尾部已改善的证据。报告中的平方低噪声gate仅作注记，没有实际施加或选用系数。

## 4. 对下一步的影响

当前不采用新loss。三组固定60k已完成，V3仍选择T2作为基础候选，正在补匹配短控制，损失与T2相同。若基础姿态尾部仍是主要问题，再在选定模型上做更完整的训练集参数梯度标定，选择有界的单因素系数；不能拿这十二条诊断样本的比例直接当作生产系数。
