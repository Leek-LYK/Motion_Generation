# 批次 m4_20261102｜M4-A/B/C/D 顺序实验

已实现并启动四阶段自动队列。执行顺序为 A 训练与评估 → B → C → D；各阶段独立随机初始化，配置和数据清单冻结。每组最多 5,000 步，具备验证早停、原子 checkpoint、断点恢复和阶段完成检查。

实验目录：`runs/m4_20261102/`。实时进度见 [queue_status.json](../../runs/m4_20261102/queue_status.json)；当前模型实际开始、结束时刻由各 run 的 UTC 时间字段记录，目录名表示实验批次。TensorBoard 为 `http://localhost:6007/`，远程 IDE 转发 6007。

## 固定数据

| 配置 | 样本数 | 每类数量 | 与其他配置关系 |
|---|---:|---:|---|
| A | 256 | 64 | B 的真子集 |
| B/C/D | 1,024 | 256 | 三组共用同一冻结清单 |
| 验证 | 64 | 16 | 每类 8 条已见文本新动作、8 条未见文本 |

类别为 walk、jog、jump、raise_arms。全部使用 M2 缓存中的完整 60–90 帧事件，沿用 M2 归一化和原始 split。不同训练配置均排除了验证中被指定为“未见文本”的原句。

按来源和 validation group 检查 train/val 交集均为零，A 完全包含于 B，未使用官方测试动作做训练或选模型。文本和同源重复有上限，B 的文本多样性高于 M3 的少数固定描述。

已查看全部 64 条验证事件的四个关键时刻、XY/ZY 两种投影，并根据发现的问题移除跳台、障碍物和吸烟候选。最终验证未见文本共 28 个独立原句，已见文本共 5 个原句；其中抬臂未见文本只有 4 个原句，需保留这一覆盖限制。

证据：[数据审计](../../runs/m4_20261102/data/audit.json)、[助手关键帧检查](../../runs/m4_20261102/data/reference_review/assistant_review.json)。人工逐帧语义审核仍为 pending，不能将关键帧检查写成完整人工或动力学验收。

## 已完成的实现验证

- Root 和 Body 均执行真实 CUDA 优化器更新。
- 在 D 同时启用文本 dropout 和 heading 增广时，连续训练与中断恢复的模型、EMA、优化器、batch/noise/text/heading RNG 逐元素一致。
- 批量 yaw 变换与官方逐样本变换一致；旋转往返最大误差约 `4.77e-6`，FK 位置旋转一致性误差约 `4.77e-7 m`。
- 显式检查文本 dropout 为 0 和 1 时的输入行为，CFG w=1 与条件预测一致，w=2 满足公式。
- 采样可复现且不改变训练调度或 RNG；未训练 null-text 的 A/B 拒绝启用额外 CFG。
- 完整验证确实覆盖 64 条事件、8 个类别/文本分组。
- 两步冒烟队列实际跑通 A、B、C、D 各自的训练和最终评估，自动衔接成功；这些短跑只验证执行流程，不用于质量比较。

证据：[数值检查](../../runs/m4_20261102/verification/report.json)、[顺序队列冒烟完成记录](../../runs/m4_20261102/queue_smoke/QUEUE_COMPLETE.json)。

## 正式实验与产物

| run | 增量实验变量 |
|---|---|
| `A_256` | 256 条，M3 同类基础训练配方 |
| `B_1024` | 只扩大到 1,024 条 |
| `C_1024_textdrop` | 加 10% 文本 dropout，评估 CFG 1/1.5/2 |
| `D_1024_heading` | 在 C 基础上加一致的全局 yaw 增广 |

统一评估完整 raw/EMA 验证集，按类别和文本分组宏平均；分别保存 `best_val_raw.pt`、`best_val_ema.pt` 和 `latest.pt`。每阶段结束后使用其最佳 EMA，评估三 seed 生成、原始与旋转 90° 验证、文本打乱诊断、受控 prompt-swap、配对位置误差和几何异常，并导出 NPZ/CSV/PNG。

根目录 `comparison.json` 随阶段完成增量更新，最终 `QUEUE_COMPLETE.json` 记录四阶段正常执行。错误会中止队列并保存日志，不会跳过失败阶段。`source_snapshot/` 保存本批次代码、配置与环境锁文件；M2 缓存和 M3 训练代码、checkpoint 均保持原样。

完整配置、曲线含义和停止/恢复命令见 [M4 使用说明](../M4顺序实验使用说明.md)。训练完成后仍需判读生成质量；自动队列完成标记不代表已经通过全部 M4 泛化验收。
