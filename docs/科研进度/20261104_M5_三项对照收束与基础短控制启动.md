## 2. 为什么必须补一个短控制

原短控制L0采用G1＋50%高噪声；选定的T2在40→60阶段采用均匀t。两者时间采样不同，不能据此把长度效果归因完整。

新的D0与已完成D1保留同一算法：

| 项目 | 新D0短控制 | 复用D1混合T2 |
|---|---|---|
| 父状态 | 原C40全状态 | 同一C40全状态 |
| 阶段 | 40→60k，新增20k | 40→60k，已完成20k |
| 训练事件 | 3,404条，60–90帧 | 3,366条，60–180帧 |
| 时间采样 | 均匀t=0…999 | 相同 |
| 目标 | raw7＋G1自一致性λ0.012261994051407363 | 相同 |
| 优化器、batch、精度 | AdamW、64/64、BF16前向/FP32参数与几何 | 相同 |
| LR、增强、dropout、EMA | origin40/end60、500步warmup；heading增强、textdrop0.1、networkdrop0；EMA10/.995 | 相同 |
| 归一化、开发/监控 | 原冻结统计，同序300/91事件 | 相同 |

短/混合是原事件课程的比较，两份训练清单并非同一批运动的不同裁剪。训练集合继续包含原六类，复杂类不作为阶段质量阻断；没有改变输入、删掉失败样本或重新拟合统计。

新D0从C40的model、EMA、optimizer、五条专用随机流及全局随机状态继续，不从T2_60多训练20k。原高噪声短控制仍保留；当前只新增一组，不启动多个依赖尚未验证的后续阶段。
