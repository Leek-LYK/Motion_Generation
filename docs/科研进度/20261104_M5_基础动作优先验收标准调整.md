# 2026-11-04｜M5 改为基础动作优先，复杂动作作为扩展测试

根据用户明确提出的调整，本阶段以小型网络的基础动作能力为主。**跳跃、快速奔跑、低姿态、大幅度舞蹈等复杂动作不再承担M5质量硬门槛**；保留生成、视频和指标，质量不足不阻断M5。后续实验不再仅为这些复杂动作未达标而反复追加。

后续更新：三组R对照的固定60k已结束，V3仍选择T2基础候选；为完成公平D0/D1比较，已单独启动同设置的均匀时间短控制。实际预算、启动与保留的完整课程要求见[三项对照收束与基础短控制启动](20261104_M5_三项对照收束与基础短控制启动.md)。

本次改变验收范围，训练数据、模型输出和旧实验结果保持原样。原V2严格标准及失败记录保留，新判断使用单独的V3基础动作版本。

## 1. 需要达到什么程度

| 动作范围 | 本阶段要求 |
|---|---|
| 常规行走、普通速度的移动/慢跑 | 作为基础动作，检查主动作、方向、幅度与稳定性 |
| 自然抬臂、放臂 | 作为基础动作；左右手语义仍保留检查 |
| 普通、非快速的转向 | 作为基础动作；检查总体幅度与语义，按长度的表现另行报告 |
| 跳跃、腾空、快速奔跑/移动 | 扩展测试，报告表现，不要求小网达到高质量 |
| 深蹲、蹲伏、爬行等低姿态 | 扩展测试 |
| 舞蹈、dab、特技、大幅旋转 | 扩展测试 |

普通的“抬手再放下”“行走后停止”不会因为出现`then`而自动归为复杂。基础组中保留左右错误、突变和姿态不合理的样本，不依据模型得分调整难度标签。

原幅度比、穿地、节点投影和连续性等数值定义不变，质量门槛改为作用于基础动作。普通转向保留总体检查，不额外引入旧版没有的逐长度转向硬门槛。基础行走、普通移动和抬臂继续报告并检查短/extended两个长度段及native/heading0两个朝向。

所有测试的有限值及有效bounded qpos继续检查；复杂动作的质量单列，不用复杂动作的改善补偿基础动作退化。M5仍限于文本到运动，不增加动力学、控制器或M6条件能力。

## 2. 难度分类已冻结

分类只使用原始提示文本及动作类型，按明确词汇标记跳跃、快速移动、低姿态、舞蹈/特技、大幅旋转。没有读取最终审计模型分数，也没有按现有输出挑选容易案例。该分类是明确的元数据规则，保留每条文本和分类理由供复核。

| raise_arms | 49 / 2 | 68 / 2 |

| jump | 0 / 64 | 0 / 110 |

300开发事件、657最终源事件仍全部保留。最终新seed审计仍生成全部657事件，基础384事件承担质量硬检查，复杂273事件作为扩展报告；没有缩成只测基础样本。

人评新版本保留120条独立源提示，其中基础四类各20条，共80条为必评部分；另40条jump/squat作为扩展展示，质量评分不阻断M5。源文本唯一、源组与训练独立，沿用原GT质量规则；选择没有使用生成分数。两位真实独立评阅者、隐藏模型身份的证据要求继续保留，基础类别宏准确率及配对偏好只计算基础部分。

## 3. 已有结果按新范围重新计算

对已完成的短控制及四格60k端点，每组从原1,800段中提取相同的1,080段基础输出；重新从原始bounded qpos和保存的FK姿态计算全部基础节点误差池，再计算pooled P95。不是用片段P95均值冒充pooled P95，没有重新采样或修改轨迹。

| 固定60k模型 | 基础动作幅度检查 | 基础FK自不一致均值 | 基础pooled节点P95 | 基础最大节点投影差 |
|---|---|---:|---:|---:|
| L0短控制 | 通过 | 2.345cm | 8.349cm | 92.323cm |
| T0无自一致性/均匀 | 通过 | 3.074cm | 7.778cm | 82.748cm |

| T3自一致性/高噪声 | 通过 | 1.919cm | 6.361cm | 122.717cm |

**T2现在通过了基础范围的相对研究保护**：相对T3没有超过既定限额的基础退化，基础幅度也不再被长跳跃阻断，可以作为后续基础配方候选。它仍需匹配短控制；当前三组R实验结束后，再共同确定下一步。

基础姿态的几何尾部仍有明显误差，绝对几何尚未满足原数值目标。排除复杂动作没有消除这项问题，后续应把重点放在普通动作的合法姿态、连续性和方向语义，而非长跳跃幅度。原T3混合/短控制的对比仍有穿地、最大节点及深穿地比例退化，保留为未通过。

长转向分层表现仍报告：例如T2 native extended仅有两条达到原幅度要求的参考运动、六个重复seed片段，其中三段非坍缩。它不再被新增为逐长度转向硬门槛；总体转向检查、人评及连续性结果继续保留。

## 4. 你已提交的真人评价如何使用

原十二提示的分数和备注均未改变。在新规则下，其中六条为基础提示，另外六条为扩展；基础四类均有覆盖：

- Small主动作5/6正确；按四类等权宏平均为87.5%。
- Tiny主动作4/6正确；四类宏平均为62.5%。

总正确率与类别宏平均使用不同分母，分开保留。Small的左臂提示错侧仍在基础集合中，没有因错误而豁免。这是一名真实评阅者对40k开发小包的反馈，样本量不足以替代最终80条基础提示及两位评阅者的证据。

## 5. 对正在进行的工作的影响

R1 dropout、R2新增十九条GT、R3幅度混合三组已经注册的训练继续原预算与原配置。V2观察器仍保存原严格结果；另加V3观察器，结束后按同一基础集合重新计算，纳入既有T2候选比较。下一步不再因复杂动作质量不足追加M5阻断研究，复杂动作本身可作为后续扩展方向。

没有新增正式训练预算，仍为495k。完整B/C、匹配D0/D1、原E0/E1、匹配Tiny与两条独立Small的完整选定课程、基本人评及最终审计/归档继续保留。新口径不等于已完成M5。

首次V3草案误把转向也加入逐长度核心硬门槛，比旧版额外增加了一项要求。已在revision2纠正，原草案和结果完整保留；分类、样本、数值阈值和源输出均未改。当前以`CURRENT_POLICY.json`所指revision2为准。
