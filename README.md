# Kimodo G1 从零复现

本目录保存数据准备、实验环境与项目文档。数据源和官方模型均保留原始文件，不覆盖 `dataset/Seed` 或 `project/kimodo` 的既有内容。

## 环境

```bash
cd /root/kube-user/lyk/project/project_mg
bash scripts/bootstrap_env.sh
source .venv/bin/activate
source ../kimodo/scripts/kimodo_env.sh
python -c 'import torch, kimodo, pyarrow, mujoco; print(torch.__version__, torch.version.cuda)'
```

`bootstrap_env.sh` 使用工作区内的 `../../.local/bin/uv`、Python 3.10 和 `uv.lock`，创建的虚拟环境提示符为 `mg_repro`，并在 `.venv/bin/uv` 建立指向该工具的链接，激活环境后可直接使用 `uv`。普通 Python 包配置为清华 PyPI 镜像，PyTorch 使用 CUDA 12.8 的官方索引。可分别通过 `UV_BIN`、`KIMODO_REPRO_PYTHON` 和 `UV_CACHE_DIR` 覆盖工具路径。

Kimodo 使用同工作区的 `../kimodo/source` 可编辑安装；脚本还将现有 Python 3.10 的 MotionCorrection 扩展接入新环境，供后处理使用。因此该环境依赖现有 Kimodo 源码和二进制扩展，尚不是完全独立的可迁移发布包。源码内已有本地 LLM2Vec 适配修复；不要未核对就替换源码或更新依赖。

G1 压缩包和元数据取自 [ModelScope BONES-SEED](https://modelscope.cn/datasets/bones-studio/seed)；划分取自 NVIDIA 的 [Kimodo Motion Generation Benchmark](https://huggingface.co/datasets/nvidia/Kimodo-Motion-Gen-Benchmark)，版本 `2727f526a0c543001d5332b6eabf72d7e3acf14a`。官方 Benchmark 当前以 SOMA 为基础，G1 评估仍需明确转换与骨架差异。

G1 压缩包 SHA-256：`52580ea8bced72ea9e2ff1e7b68f01c51c7f1099581e9a46b7c87e1dec106d8a`。元数据 Parquet SHA-256：`7cbe5624f91ae19af3feee69cff74b2cf553fb26367c8edc4b674c3d8ea97e7d`；时间轴 JSONL SHA-256：`302da3c319bbed4f712fa22a4d71b5288493911140cd72579e29de2ac324d634`。

下载中断后可执行 `python scripts/download_seed_g1.py`，该脚本使用 256 MiB 分段、保留已有分段并核对最终 SHA-256。需要已完成环境安装。脚本使用锁定的 `modelscope-hub==0.4.6` 的内部分段下载接口，因此升级该依赖前需重新验证。

`python scripts/audit_seed_inputs.py` 写入 `reports/seed_raw_audit.json`，检查元数据、标注、划分及已解压 G1 文件的基本覆盖。该检查不代替运动回放、重采样和文本时间窗的人工核验。

已下载的 G1 数据包含 142,220 个 CSV，元数据中的文件名和完整路径均与其一一对应，时间轴标注覆盖相同的 142,220 个动作；随机抽取的 200 个同步文件通过 SHA-256 比对，结果见 `reports/g1_copy_sample.json`。官方三个 split 的路径和文件名无交集；其中训练 split 有 36 条路径在当前元数据和标注中未匹配。必须保留并调查这些条目，不将其作为已通过的训练样本。

原始 120 Hz 动作的 120→30 Hz 单条转换已完成冒烟检查。现有 Kimodo 源码的 50→30 Hz 四元数插值在部分数据上会产生非有限值；证据和失败样本位于 `reports/env_smoke_20261030/`，修复前不要将该路径用于训练数据。官方 Benchmark 的完整 `testsuite/` 尚未下载，本次仅准备必需的三个划分文件。

`data/`、`.venv/` 和日志不进入 Git。详细实验规划见 `docs/`。
